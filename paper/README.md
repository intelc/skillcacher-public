# skillcacher paper

ACM-style systems paper using `acmart.cls` (the universal ACM
template for SIGMOD, OSDI, SOSP, MLSys, ASPLOS, etc.). Two-column
sigconf layout.

## Layout

```
paper/
├── main.tex                  # root document, acmart preamble, \input section files
├── sections/
│   ├── 00-abstract.tex
│   ├── 01-introduction.tex
│   ├── 02-background.tex
│   ├── 03-system.tex
│   ├── 04-benchmark.tex
│   ├── 05-evaluation.tex
│   ├── 06-discussion.tex
│   ├── 07-related.tex
│   ├── 08-conclusion.tex
│   └── 09-appendix.tex
├── refs.bib                  # bibtex (vllm, lmcache, cacheblend, swe-bench, etc.)
├── figures/                  # generated PDFs (gitignored — rebuilt via `make figures`)
├── data/                     # CSV inputs for figures (figures read benchmark/ directly)
├── scripts/
│   └── make_figures.py       # matplotlib generator, reads benchmark/results/
└── Makefile
```

## Build setup (one-time)

LaTeX toolchain is not installed by default on macOS. We recommend
**BasicTeX** (~100 MB) over MacTeX (~5 GB) — `acmart.cls` and its
dependencies are small.

```sh
brew install --cask basictex
# After install, may need to restart shell or:
eval "$(/usr/libexec/path_helper)"

# Required acmart packages — basictex is minimal, install on demand:
sudo tlmgr update --self
sudo tlmgr install latexmk acmart booktabs microtype xcolor \
    pgf preview ifmtarg biblatex-trad ulem subcaption ms tools \
    geometry trimspaces hyperref totpages environ tikzfill \
    pdfcol kvoptions inconsolata mweights ncctools
```

If `tlmgr install` fails on any individual package, drop it and retry —
acmart picks them up from the recommended-package mirror.

## Build

```sh
cd paper

# Regenerate figures from benchmark data
make figures

# Build the PDF
make pdf            # produces main.pdf

# Iterate (rebuild on save)
make watch          # latexmk -pvc

# Cleanup
make clean          # remove .aux/.bbl/.log etc.
make distclean      # also remove main.pdf and figures/
```

## Editing notes

- **`\todo{}` markers** render in red; search for `\todo{` to find open threads.
- **`\note{}`** is for inline drafting comments that should NOT make it into the
  final PDF — set `\renewcommand{\note}[1]{}` in `main.tex` to suppress
  before submission.
- **Figures are PDFs.** `\includegraphics[width=\columnwidth]{figures/X.pdf}`.
  TikZ figures are inline in the `.tex`.
- **Anonymization.** Author block in `main.tex` is non-anonymous. For
  double-blind submission, switch `nonacm=true` $\to$ `anonymous=true` in the
  `\documentclass` line.

## Source data

Figures depend on `benchmark/results/` which is gitignored — see the
top-level repo README for how to regenerate or download the inputs from
[`intelchen/claudecode-trace`](https://huggingface.co/datasets/intelchen/claudecode-trace)
on Hugging Face.
